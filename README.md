# 天猫优惠券使用预测

用逻辑回归预测哪些用户更可能使用优惠券，并据此给出发券建议和 A/B 实验方案。

## 业务问题

为了提高优惠券的使用率，根据用户的年龄、婚姻、职业、贷款等属性，以及过去是否用过优惠券的行为，预测每个用户是否会使用优惠券，从而把券优先发给模型预测用券概率高的用户，并通过实验验证发券是否真的带来额外消费。

## 数据

- 文件：`tianmao.csv`，25,317 行、10 列，目标列 `coupon_ind`（是否使用优惠券，用券比例约 11.7%）。
- 字段：ID、age、job、marital、default（花呗是否违约）、returned（是否退货）、loan（是否用花呗结账）、coupon_used_in_last6_month、coupon_used_in_last_month、coupon_ind。
- 来源：数据来自网上购买的一份数据分析练习项目，原始出处不明。字段结构（job、marital、default、loan 等及其取值）与公开的 UCI Bank Marketing 数据集很相似，推测是由它改编的，"天猫"场景可能是模拟的。因版权原因，本仓库不包含数据文件。
- 放置位置：如需运行，把 `tianmao.csv` 放到 `data/` 文件夹下（`data/tianmao.csv`）。

## 主要结论

1. **数据**：没有空值；job 里有 163 个 unknown，保留为单独类别；去掉 ID 后的重复行是字段少、取值少造成的自然重复，保留。
2. **单变量分析**：学生（26.8%）和 60 岁以上用户（约 43%）用券率最高；用券率随年龄呈 U 型，所以两组平均年龄几乎一样。Cramér's V 显示年龄段、是否退货、职业和用券关系最强。
3. **模型**：样本不平衡，默认阈值 0.5 时准确率 0.882，反而略低于"全猜不用券"的 0.883，888 个用券者只找出 29 个。
   - `class_weight='balanced'` 和降低阈值效果基本一样，两个模型 AUC 都是 0.713，区分能力没有变。
   - 用边际分析选阈值：每降一档阈值，看新增券的命中率是否高于随机发券（11.7%）。最终选 0.15：发券 1794 张，找到约一半用券者，命中率约 25%，是随机发券的 2.1 倍。
4. **A/B 实验**：模型只能说明"谁可能用券"，不能说明"是不是券让他买的"。方案是把模型选中的用户随机分成发券组和不发券组，核心指标为人均利润，护栏指标为退货率和停券后复购率；每组 900 人只能检测出约 4.6 个百分点的提升。
